# Privacy policy

Webtor Chrome extension collects downloaded torrent files and clicked magnet-urls, transmits them to https://webtor.io for further processing (online streaming or direct download).

To get a downloaded torrent file's contents, the extension requests it once more from the address it was downloaded from, from the site's own open tab where possible. Nothing else is read from that site, and the file goes nowhere but https://webtor.io. Files downloaded from webtor.io itself are left as they are, and a download that is not a torrent file (for example a login page saved under a .torrent name) is not sent.
